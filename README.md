# 금융시장 분석가 공부방

경제신문 독해부터 기업분석·주식·비트코인 시황 작성까지, 하루 5시간(50분 × 6교시) 90일 과정의 학습 프로그램입니다.

- 학습자 주소: 이 저장소의 GitHub Pages 주소 (예: `https://leeahyung-alt.github.io/study/`)
- 관리자(함께 보기) 주소: 같은 주소 끝에 `#view` (예: `https://leeahyung-alt.github.io/study/#view`) — 읽기 전용

## 기록은 어디에 저장되나요
- 학습자 기기의 브라우저(IndexedDB)에 먼저 저장됩니다.
- `index.html` 안의 `SYNC_URL`(Google Apps Script 웹 앱)이 설정되어 있으면, 관리자 Google 드라이브의 `금융공부방_기록` 폴더에 `learner.json`으로 함께 저장됩니다.
- 주소를 아는 사람은 기록을 볼 수 있습니다. 기록을 바꾸려면 학습자가 처음 정한 비밀번호가 필요합니다.

## 비밀번호를 잊었을 때
Apps Script 편집기 → 왼쪽 톱니바퀴(프로젝트 설정) → 스크립트 속성 → `pin_learner` 삭제 → 학습자가 다음에 접속해 ‘설정 → 비밀번호 입력’에서 새 비밀번호를 넣으면 다시 등록됩니다.

## 교재 구성
- 75개 학습일(일자별 어휘·지문·뉴스·기업·시장·글쓰기), 12개 주간 복습일, 첫날 진단과 7·14·30·60·90일 평가
- 개념 134개, 영역별 평가 문항 210개(7개 영역 × 6레벨 × 5문항)
- 기업·뉴스·시장 사례는 모두 교육용 가상 자료입니다. 실제 자료는 프로그램 안에서 직접 붙여넣어 분석합니다.
