# 콘텐츠 작성 규격 (금융시장 분석가 양성 90일 과정)

학습자: 금융 지식이 거의 없는 성인. 어휘·독해력은 중학생 수준 이하일 수 있다. 하루 5시간(50분×6교시) 공부한다.
최종 목표: 경제신문을 정확히 읽고, 기업·뉴스·주식·비트코인 시장을 근거로 분석하고, 전문적인 시황·기업 코멘트를 쓰는 수준.
처음은 아주 쉽게 시작하되, 뒤로 갈수록 실제 분석가 수준의 사고를 요구한다.

## 공통 규칙 (반드시 지킬 것)
1. 한국어로 쓴다. 학습자에게 하는 설명·질문·해설은 쉬운 해요체("~예요", "~해 보세요"). 지문·기사·모범답안은 문어체("~다").
2. **가상 사례 표시**: 기업 사례·뉴스·시장 자료는 모두 교육용 가상 사례다. 기업 이름은 지어낸 이름만 쓴다(예: 푸른빵, 한빛전자, 새솔건설, 다온모빌리티). 삼성·현대·SK·LG·네이버·카카오·애플·엔비디아·테슬라 등 실제 기업 이름을 가상 수치와 함께 쓰지 않는다. 한국은행, 연준(Fed), 코스피, 나스닥, 비트코인, 이더리움, DART처럼 제도·지수·자산 이름은 써도 된다. 단 가상 수치를 실제 날짜의 실제 값처럼 쓰지 않는다(날짜는 "가상 시장일"처럼 표기).
3. **역사·제도 사실**은 정확하고 널리 확인된 것만 쓴다(예: 비트코인 발행 한도 2,100만 개, 2008년 금융위기와 리먼브라더스 파산, 1997년 외환위기와 IMF 구제금융, 2000년 닷컴 버블). 확실하지 않은 세부 숫자는 쓰지 않는다.
4. 계산은 반드시 맞아야 한다. 표의 숫자끼리 서로 맞아야 한다(합계, 증감률, 이익 = 매출 − 비용 등). 작성 후 직접 다시 계산해 확인한다.
5. 객관식은 정답이 하나뿐이어야 하고, 오답 보기는 그럴듯해야 한다(초보자가 자주 하는 오해를 오답으로). 해설(explain)은 왜 정답인지와 왜 대표 오답이 틀렸는지 1~3문장으로 가르친다.
6. 투자 권유를 하지 않는다. 위험·손실 가능성이 관련되면 언급한다.
7. 같은 질문·지문을 다른 날에 그대로 반복하지 않는다. 날마다 새로운 내용이거나 이전 개념을 더 높은 수준에서 쓰는 과제여야 한다.
8. 질문은 7단계 사고 순서를 따른다: ①무엇이 사실인가 ②무슨 뜻인가 ③왜 일어났나 ④다른 현상과 어떻게 연결되나 ⑤내가 아직 모르는 것은 ⑥어떤 판단을 할 수 있나 ⑦내 판단이 틀릴 수 있는 이유는. 앞 단계일수록 쉬운 질문, 뒤로 갈수록 사고 질문의 비중을 높인다.
9. 서술형(free)은 정답 하나를 강요하지 않는다. keyPoints(2~5개, 학습자가 자기 답과 대조할 수 있는 짧은 점검 항목)와 model(모범답안)을 준다. 시장 원인 분석은 "가능한 설명"과 "자료로 확인된 원인"을 구분한다.

## 난이도 단계 (지문 level)
- R1 (1~10일): 150~250자, 한 문장 25자 안팎, 쉬운 낱말, 문장마다 한 가지 정보.
- R2 (11~30일): 300~500자, 원인-결과가 드러나는 짧은 글.
- R3 (31~45일): 500~800자, 경제기사 수준의 문단 2~3개.
- R4 (46~60일): 800~1100자, 여러 요인이 얽힌 해설 기사.
- R5 (61~75일): 1000~1400자, 분석글(주장과 근거).
- R6 (76~90일): 1300~1800자, 반론과 단서가 포함된 분석글.

## 질문 객체 Q
- 객관식: `{"t":"mcq","stem":"...","options":["...","...","...","..."],"answer":0,"explain":"...","skill":"main|detail|vocab|cause|inference|structure|calc|link|judge|counter|fact","lv":1}`
- 숫자: `{"t":"num","stem":"...","answer":12.5,"tol":0.1,"unit":"%","explain":"계산 과정","skill":"calc","lv":1}`
- 서술: `{"t":"free","stem":"...","keyPoints":["...","..."],"model":"...","skill":"...","lv":1}`
lv는 1~6 (그 문항이 요구하는 수준). options는 3~4개.

## 일자 콘텐츠 파일: `content/days/dNNN.json` (예: d001.json) — 하루 1파일
```json
{
 "day": 1,
 "vocab": [ {"w":"소득","m":"일하거나 가진 것으로 벌어들인 돈","ex":"오늘 지문에서 쓰인 뜻이 드러나는 예문","q":{"t":"mcq","stem":"빈칸 문장 ___","options":["소득","부채","세금","이자"],"answer":0,"explain":"...","skill":"vocab","lv":1}} ],
 "reading": {"title":"...","level":1,"text":"문단은 \n\n 으로 구분","easy":"같은 내용을 더 짧고 쉬운 문장으로 다시 쓴 버전","key":"본문에서 가장 중요한 문장(본문 문장 그대로)","qs":[Q,Q,Q,Q,Q],"sum":{"prompt":"자기 말로 요약하는 과제","keyPoints":["..."],"model":"..."}},
 "news": {"headline":"...","source":"교육용 가상 기사","dateLabel":"가상 사례","body":"...","qs":[Q,Q],"steps":[{"k":"fact","q":"무엇이 사실인가요?","hint":"...","model":"..."}],"record":{"stakeholders":"주요 이해관계자","impactShort":"단기 영향","impactLong":"중장기 영향","stockLink":"주식시장과의 연관","btcLink":"비트코인과의 연관(없으면 '직접 연관 적음' 등)"}},
 "company": {"mode":"case|dart|idea","title":"...","firm":"가상 기업명","text":"사례 설명 또는 사업보고서 연습 발췌","table":{"caption":"표 제목 (단위: 억원)","head":["항목","2024년","2025년"],"rows":[["매출액","1,000","1,200"]]},"qs":[Q,Q,Q,Q],"apply":"(dart·idea 모드) 학습자가 고른 실제 기업에 같은 질문을 적용하는 과제 문장"},
 "market": {"title":"...","dateLabel":"가상 시장일","table":{"caption":"...","head":[...],"rows":[[...]]},"notes":["자료에 적힌 사실 메모 2~4개"],"qs":[Q,Q,Q],"classify":[{"s":"판단할 문장","a":"fact|possible|verified","why":"이유"}]},
 "writing": {"type":"concept|news|company|stock|crypto|macro","prompt":"과제 설명","frame":["문장 틀(초반에만, 뒤로 갈수록 줄이고 3단계에서는 빈 배열)"],"size":"예: 1문장 / 3문장 / 1문단 / 3문단","keyPoints":["좋은 답에 들어갈 요소"],"model":"모범 글"}
}
```
분량 기준(하루 50분×5교시를 실제로 채울 수 있게):
- vocab 4개: 오늘 reading에 실제로 나오는 낱말(경제 용어가 아닌 일반 어휘·한자어도 포함, 예: 둔화, 반등, 우려, 전망, 감소, 기인). 개념(concepts) 이름과 겹치지 않게.
- reading.qs 5~7개: main 1, detail 1~2, vocab(문맥 속 뜻) 1, cause 1, inference 1, (1~10일은 structure: 문장의 핵심 찾기 1). R4 이상은 judge/counter 포함.
- news.steps: 1~13일 fact·meaning·why 3개 / 15~29일 + link·unknown 5개 / 31일 이후 7개 전부(fact, meaning, why, link, unknown, judge, counter). news.qs 2~3개: 사실/의견 구별, 중요도(이 뉴스가 중요한 이유 고르기), 31일 이후 "이미 시장에 알려진 것인가" 포함.
- company.qs 4~5개 (계산 1개 이상 포함 권장). dart 모드는 연습 발췌(가상 기업의 사업보고서 일부처럼 쓴 글 + 표)를 주고, 그 발췌에 대한 질문 + apply 문장.
- market.qs 3~5개 + classify 3~4개. 31일 이후 비트코인 파생 지표(펀딩비·미결제약정·청산·ETF 유입)를 다루는 날은 그 수치를 표에 넣는다.
- writing: 1~13일 frame 2~3개, 15~29일 frame 1~2개, 31~60일 frame 1개(첫 문장만), 61일 이후 frame 없음.

## 개념 파일: `content/concepts/<id>.json` — 개념 1개 1파일
```json
{"id":"revenue","name":"매출(매출액)","easy":"아주 쉬운 2~3문장 설명","analogy":"일상 비유 1~2문장","real":"기업·시장에서의 실제 의미 2~4문장(정확하게)","example":"이 개념이 들어간 뉴스식 예문 1문장(가상)","alt":"첫 설명을 이해 못 했을 때 다른 각도의 설명 2~3문장","altExample":"다른 예시 1~2문장","links":[{"to":"op_profit","why":"연결 이유 한 문장"}],"canDo":"이 개념을 익히면 할 수 있는 일(…을 설명할 수 있다)","quiz":[Q,Q,Q,Q],"explain":{"prompt":"자기 말로 설명하기 과제","keyPoints":["..."],"model":"..."}}
```
- quiz 4개: 기억 1, 이해 1, 적용 1, **transfer 1(처음 보는 상황에 적용, Q에 "transfer":true 추가)**. 객관식 위주, 계산 개념은 num 1개 포함.
- links는 concepts_list.json에 있는 id만 쓴다. 이전에 배운 개념(그 개념보다 day가 작은 것)과의 연결을 우선한다.

## 평가 문항 파일: `content/assess/<domain>.json` — 영역별 배열
```json
[{"id":"A-R-3-01","d":"R","lv":3,"t":"mcq","passage":"(필요하면) 짧은 지문","stem":"...","options":["..."],"answer":1,"explain":"..."}]
```
영역 d: R 독해력, V 어휘·시사 상식, E 경제·금융 이해력, N 뉴스 분석력, C 기업분석·투자 아이디어, M 주식·비트코인 시장 분석력, W 논리적 글쓰기·시황 작성(객관식으로 측정 가능한 부분: 더 정확한 문장 고르기, 근거 없는 주장 찾기, 논리 순서, 사실·의견 구별, 반론 고르기, 시황 문단에서 오류 찾기).
레벨 기준(영역 공통 해석):
- 1 문장 이해: 기초 용어 뜻, 짧은 문장 한 개의 의미
- 2 정보 이해: 짧은 기사·자료에서 핵심과 원인 구분, 표 숫자 읽기
- 3 관계 연결: 금리·환율·물가·실적 등 두세 개념의 연결 추론
- 4 기초 분석: 근거·장단점·위험 찾기, 숫자 사이 이상한 점 발견
- 5 독립 분석: 여러 자료 비교, 근거 있는 결론 선택
- 6 종합 분석: 기업·산업·거시·수급·기대 차이를 종합, 반론과 한계 판단
평가 문항은 일자 콘텐츠나 개념 퀴즈와 겹치면 안 된다(처음 보는 지문·상황). 학습 내용 응용 여부를 확인하는 문항이어야 한다.
